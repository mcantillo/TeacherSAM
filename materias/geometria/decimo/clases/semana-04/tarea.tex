% Ejercicio: geometria-analitica-10-040
\pregunta[1] Calcula la distancia entre cada pareja de puntos y deja el resultado exacto.
\begin{opciones*}(3)
  \item $A(2, 3)$ y $B(6, 6)$
  \item $C(-3, 2)$ y $D(5, -4)$
  \item $E(1, -2)$ y $F(7, 6)$
\end{opciones*}
\begin{solucion}[4cm]
a) $\sqrt{4^2 + 3^2} = \sqrt{25} = 5$. \quad b) $\sqrt{8^2 + (-6)^2} = \sqrt{100} = 10$. \quad
c) $\sqrt{6^2 + 8^2} = \sqrt{100} = 10$.

Los tres son ternas pitagóricas: $3$-$4$-$5$, $6$-$8$-$10$ y $6$-$8$-$10$.
\end{solucion}

% Ejercicio: geometria-analitica-10-041
\pregunta[1.5] Los vértices de un triángulo son $P(1, 1)$, $Q(5, 1)$ y $R(3, 5)$. Calcula la
longitud de sus tres lados y decide si el triángulo es equilátero, isósceles o escaleno.
Justifica con los números, no con el dibujo.
\begin{solucion}[4.5cm]
$PQ = \sqrt{4^2 + 0^2} = 4$; \quad $QR = \sqrt{(-2)^2 + 4^2} = \sqrt{20} = 2\sqrt{5}$; \quad
$PR = \sqrt{2^2 + 4^2} = \sqrt{20} = 2\sqrt{5}$.

Como $QR = PR \neq PQ$, el triángulo es \textbf{isósceles}. Medir con regla sobre el dibujo no
bastaría: $\sqrt{20} \approx \num{4,47}$ se parece mucho a $4$.
\end{solucion}

% Ejercicio: geometria-analitica-10-042
\pregunta[1.5] Un cuadrilátero tiene vértices $A(0, 0)$, $B(4, 3)$, $C(8, 0)$ y $D(4, -3)$.
Calcula $AB$, $BC$, $CD$ y $DA$. ¿Qué tienen en común los cuatro lados? ¿Basta eso para
afirmar que es un cuadrado? Calcula también las dos diagonales $AC$ y $BD$ y decide.
\begin{solucion}[5cm]
Los cuatro lados miden $5$: $AB = \sqrt{4^2 + 3^2} = 5$, y lo mismo $BC$, $CD$ y $DA$.

Tener los cuatro lados iguales lo hace un \textbf{rombo}, pero \emph{no} basta para decir que
es un cuadrado. Las diagonales lo resuelven: $AC = 8$ y $BD = 6$. En un cuadrado las dos
diagonales miden lo mismo, así que este rombo no es un cuadrado.
\end{solucion}

% Ejercicio: geometria-analitica-10-043
\pregunta[1] Camila calculó así la distancia entre $M(-2, 5)$ y $N(4, -3)$:
\[ d = \sqrt{(4 - 2)^2 + (-3 - 5)^2} = \sqrt{4 + 64} = \sqrt{68}. \]
Encuentra el error, corrígelo y explica en una frase por qué el resultado correcto no cambia
si se intercambian $M$ y $N$.
\begin{solucion}[4cm]
El error está en la resta de las abscisas: es $4 - (-2) = 6$, no $4 - 2 = 2$.

Lo correcto es $d = \sqrt{6^2 + (-8)^2} = \sqrt{36 + 64} = \sqrt{100} = 10$. Intercambiar los
puntos no cambia nada porque las diferencias solo cambian de signo y van elevadas al cuadrado.
\end{solucion}
