# TeacherSAM

Materiales de clase de Matemáticas y Física de María Mercedes Cantillo, Colegio San Alberto
Magno (Cali, Colombia): guías del estudiante, clases, quices, talleres, tareas y evaluaciones en
LaTeX, con un banco de ejercicios verificados con Python y SymPy.

Se trabaja con Claude Code y Claude Cowork. Las instrucciones para el agente están en
`CLAUDE.md`, y la guía para la docente en `GUIA-CLAUDE-CODE.md`.

## Requisitos

- LaTeX (`latexmk`) para compilar los documentos.
- Python 3 con las dependencias de `tools/requirements.txt`:
  `python3 -m pip install -r tools/requirements.txt`
